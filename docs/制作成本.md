# 制作成本

下面是按制作会话里记录的实际用量、用官方公开 API 单价折算的数字，不是账单。

## 影视级版（本仓库）

约 **3159 万 TOKEN，折合约 165 元**，制作用时约 1 小时 16 分（2026-11-13）。

| 部分 | TOKEN | 折合人民币 |
| --- | ---: | ---: |
| Claude Fable 5.2（制作全程） | 30,299,787 | 约 160.36 元 |
| Codex gpt-5.6-terra（24 次出图调用的文字部分） | 1,294,543 | 约 5.12 元 |
| 合计 | 31,594,330 | 约 165.48 元 |

## 连同它所基于的原版

影视级版不是从零做的：七幕的动线、小猫的骨骼和动作数据、声音、文案都沿用了同一天早些时候做的 2D 绘本风原版（原版没有放进本仓库）。把原版也算上：

| | TOKEN | 折合人民币 |
| --- | ---: | ---: |
| 原版（Claude Fable 5.2，约 7 小时 40 分，39 轮迭代） | 124,091,707 | 约 437.77 元 |
| 影视级版 | 31,594,330 | 约 165.48 元 |
| 两版合计 | 155,686,037 | 约 603.25 元 |

## 口径

- 单价（美元 / 百万 TOKEN）：Claude Fable 5.2 输入 8、1 小时缓存写入 16、缓存读取 0.20、输出 40；gpt-5.6-terra 输入 2、缓存命中 0.20、输出 12。均为 2026-11-14 查到的官方公开价。汇率 1 美元 = 6.684938 元。
- 两版合计里缓存读取约 1.529 亿 TOKEN，占总量 98%，但只占费用的三分之一左右。
- 只算制作，不含事后算账、录演示视频和开源整理。
- 没算进去的：24 张图由 Codex 内置出图工具生成，这一步没有用量记录，估算另加约 30 元，无法核实。
- 实际扣费方式（订阅还是按量）与这里的折算价无关。
