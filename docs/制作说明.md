## 每一轮按「这一帧像不像电影剧照，最假的是哪一处」改了什么

### 定调

从旧版截了第一幕「小猫探头」那一张，交给 Codex 生成影视级版本。定下来的东西：左上方来的午后暖光、墨绿灰泥墙、木桌面、浅景深、胶片颗粒、真实小猫的毛和眼睛。之后所有底图都带着这张图一起生成。

### 第一轮：七幕全部换成这个风格

- 七幕的背景全部重新生成并替换，10 张示例照片和 1 段短视频也重做成同一种质感。
- 小猫从矢量画换成真实毛皮，骨骼和动作数据沿用旧版。
- 界面减重：旁白改成字幕，提示改成半透明小条，加了颗粒、暗角和光里的浮尘。
- 这一轮自己看图后改掉的最假的地方：
  - 小猫抠图边缘有一圈紫边 → 换了抠蓝算法并把边缘颜色往外扩。
  - 小猫胸口缺一块、尾巴根和身体脱开、腿弯处有扇形折痕 → 重切躯干、移尾巴根、放软关节。
  - 坐姿和睡姿悬在地面上、切换时有重影 → 按脚底对齐、收窄过渡。
  - 第三幕的灯箱太薄，像一条线 → 重新生成一张高灯箱的底图。
  - 第七幕关灯只是盖一层黑 → 改成整间屋子压成夜色，每开一盏灯在那盏灯周围透出暖光。
  - 第四幕长椅上的叶子是画死在底图上的 → 切成单独一层，底下补成长椅木条。

### 第二轮

- **最假的是小猫身上的光**：每一幕它都是同一种平光，像贴上去的。改成按每一幕的主光方向给它亮面、暗面和影子朝向（第三幕光从脚下的灯箱往上打，第六幕走向门时光从门那边来），贴地一圈压暗。
- 第一幕撕到一半时，暗处的小猫是一只发灰的「黑猫」→ 改成只在盒子深处露出轮廓，上亮下暗。
- 第一幕小猫跳出来后，「跟上它」按钮压在小猫腿上、掉出来的照片被提示条切掉 → 小猫和照片的落点上移。
- 第一幕撕开的纸边卷得太宽，像贴纸 → 收窄。
- 第四幕地点上冒出来的「记录」是线描图标 → 换成那条记录自己的小照片（视频带播放钮）或小纸条。
- 第七幕灯和蜡烛上的白圈像界面按钮 → 去掉圈，只留一点像灯丝余温的微光。
- 第一、五、六幕加了光柱里的浮尘。

## 哪些幕到了「电影剧照」，哪些没到

| 幕 | 判断 | 还假的地方 |
| --- | --- | --- |
| 第一幕 拆礼物 | **到了**（探头那一帧就是定调图本身） | 撕纸过程中的纸边是代码画的，比底图里真的撕边平 |
| 第二幕 照相馆 | 静止时到了 | 吐出来的照片、胶卷罐、胶卷条、背面便签是代码画的，和实拍感的相机放在一起能看出来 |
| 第三幕 胶卷 | **没到** | 胶卷本身是平的色块加齿孔，没有胶片的反光和弯曲；这一幕上半屏好看，中间主体最弱 |
| 第四幕 小镇 | 接近 | 底图只有约 1.35 倍像素，手机高分屏上略软；小猫是写实的，小镇是毛毡模型，两种材质放一起不完全统一 |
| 第五幕 小卖部 | **到了** | 老虎机转轮上的字是网页字体 |
| 第六幕 写给你的话 | 接近 | 信纸和刮刮层是代码画的大块平面，占了半屏 |
| 第七幕 生日房间 | **到了**（亮灯后和趴下那两帧） | 照片墙上的便签和车票是代码画的 |

贯穿全片的短板是**小猫**：它站着走动时只有一张正面的头，回头和转身是靠平移和压扁做的，不是真的转头；走路时腿的毛皮是沿骨骼拉伸的，慢放能看出不是真的肌肉运动。坐着、睡着、探头这三个静止姿势是整张生成图，最像真的。

## 没做的

- 没有给小猫做多角度的头（侧脸、回头各一张）和逐帧的走路。
- 第二、三、六幕里代码画的道具（胶卷条、胶卷罐、信纸、刮刮层）没有换成生成素材。
- 第四幕底图没有做更高分辨率的版本。
- 声音没动，沿用旧版。
- 桌面端和旧版一样，是居中的一条手机宽度的画面，两侧留暗，没有为宽屏另做构图。

## 没验证的

- **没有在真手机上看过。** 所有走查都是本机 Chrome 模拟手机（390×844、360×640）和桌面（1440×900）。
- 没有在 Safari / iOS 内核上跑过。第七幕开灯用的遮罩合成写了 WebKit 的写法，但没实测。
- 真实触摸手势只测了第一幕的撕纸和碰爪子；其余各幕走的是「替代按钮」路径，拖胶卷、拉摇杆、刮刮卡、拖叶子这几个手势在新版上没有用模拟触摸重测（这部分代码没改，只换了画面和坐标）。
- 没有测弱网下的加载时间；全部素材约 4 MB。
- `cat-lab.html` 动作试验页能打开、无报错，但它是浅色背景，小猫边缘能看到一点残留的紫边（正片是深色背景，看不出来）。

## 已验证的

线上版三种尺寸从第一幕连续走到第七幕（含回忆册、纪念卡、菜单、断点续玩），均无脚本报错；第一幕真实触摸手势走通。
